# FaceAttend AI
### AI-Based Face Recognition Attendance Management System

FaceAttend AI is a web-based attendance management system developed to simplify student attendance using face recognition technology.

The project is designed for educational institutions and provides separate access for administrators, teachers and students.

## Features

- Institute registration and management
- Role-based access for Admin, Teachers and Students
- Student and teacher profile management
- Student photo and face enrollment
- Face recognition-based attendance
- Attendance history and reports
- Attendance statistics and dashboards
- Excel report generation
- Responsive user interface

## User Roles

**Main Admin**
- Manage institute information
- Create and manage teacher accounts
- Manage institute settings

**Teacher**
- Manage assigned students and classes
- Enroll student face data
- Record and monitor attendance
- View attendance reports

**Student**
- View personal attendance records
- Check attendance percentage
- Access permitted academic information

## Technology Stack

- Frontend: React, TypeScript
- Styling: Tailwind CSS
- Backend: Supabase
- Database: PostgreSQL
- Authentication: Supabase Auth
- Storage: Supabase Storage
- Face Recognition: Face Recognition Models

## Installation

```bash
git clone https://github.com/Prakhar3106/FaceAttend-AI.git
cd FaceAttend-AI
npm install
npm run dev
```
